# 9099 · Where the Light Rests

原创水彩立体书风格的沉浸式诗歌网页。

## Features
- 五个场景：大树、乡野、石桥、草地、远山
- Three.js 前中远景分层与柔和视差
- GSAP ScrollTrigger 诗歌文字渐显
- 低饱和莫兰迪水彩风格，移动端适配
- 尊重 prefers-reduced-motion

## 运行
打开 VS Code Live Server，或在项目目录运行：

```bash
python -m http.server 8000
```

访问 http://localhost:8000

需要联网加载 CDN 中的 Three.js、GSAP 和 Google Fonts。

## 在线部署
GitHub 仓库中选择 Settings → Pages → Build and deployment → Deploy from a branch → main / root → Save。
稍后访问 https://guo1xin.github.io/9099/ （仅在 Pages 部署成功后可用）。
